# Sphere Volume Calculator

A small C++ console application that calculates the volume of a sphere.

## Description

The program asks the user to select a unit and enter the radius of a sphere.

It then calculates the volume using the mathematical formula:

V = (4/3) * π * r³

Supported units:
- Meters
- Centimeters
- Millimeters

## Features

- Unit selection
- Radius input
- Input validation
- Sphere volume calculation
- Results displayed with the selected unit
